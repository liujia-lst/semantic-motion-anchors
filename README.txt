Semantic Motion Anchors and SEMANTIX

Static research website: index.html is the paper page; dataset.html is the dataset overview.
All presentation assets are local; no install or build is required.

GitHub Pages deployment
1. Upload this folder's contents to the root of a GitHub repository.
2. In Settings > Pages, select Deploy from a branch.
3. Select the main branch and /(root), then save.
4. Wait for GitHub Pages to finish deployment and open the URL shown in Settings.

The .nojekyll file enables plain static-file publishing.
Keep the css/, js/, and images/ directory structure intact.
Do not upload the outer ZIP as a website file; extract it first.

Research text, figures and citations retain their source attribution in the pages.
The visual layout follows the requested Nerfies/MUStReason references.
No visitor analytics are included.
